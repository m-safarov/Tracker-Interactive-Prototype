# Промпт для каркаса Tracker

Подготовь пустую структуру в существующем проекте Next.js App Router, в которой легко разобраться двум начинающим разработчикам. Возьми названия страниц, вложенность и отдельные диалоги из прототипа. [Tracker в Figma](https://www.figma.com/design/VDtvtPvAQy2ZwdxDJjMHTx/Tracker-%E2%80%94-Interactive-Prototype?node-id=0-1)

- Каждой странице дай папку внутри `app/` и один пустой компонент с названием страницы. Например, для Profile нужны `app/profile/profile.tsx` и однострочный `app/profile/page.tsx`, который экспортирует этот компонент для Next.js. Подстраницы сложи внутрь папки родительской страницы.
- Рядом с каждым компонентом положи пустой `page-translations.json` с полями `en`, `tg` и `ru`. Оставь эти файлы для ручного заполнения. Весь каркас должен работать по обычным URL, например `/profile`.
- Пустые диалоги держи в папке `dialogs/` рядом с их страницей. Сохрани настроенный shadcn/ui и примитивы Button, Dialog и Sheet в `components/ui/`.
- Ограничь реализацию структурой файлов, маршрутами и настройками shadcn/ui. В коротком README покажи на примере Profile файл компонента, файл переводов и вложенную страницу на примере Tasks → Board. Для командной работы предложи распределить папки страниц между двумя ветками.
- Проверь lint, TypeScript и production build. Подготовь файлы для отправки владельцем репозитория на GitHub.
